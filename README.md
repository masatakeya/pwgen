# pwgen — パスワード生成ツール

ブラウザだけで動く、シンプルなパスワード生成ツールです。
HTML ファイル1つで完結しており、生成したパスワードがサーバーに送られることはありません。

## 特徴

- **ブラウザ完結**：インストール不要。`index.html` を開くだけで使えます
- **安全な乱数**：`crypto.getRandomValues()` を使用し、剰余による偏りが出ないよう棄却サンプリングで文字を選びます
- **文字種を必ず含む**：選んだ文字種（大文字・小文字・数字・記号）がそれぞれ1文字以上入るまで作り直します。位置や文字に偏りは出ません
- **強度の目安を表示**：設定に応じたエントロピー（bit）を計算し、「弱い／普通／強い／非常に強い」で表示します
- **まとめて生成**：最大20件を一度に生成し、1件ずつ、またはすべてをコピーできます
- **見やすい表示**：大文字・小文字・数字・記号を色分けして表示します
- **ダークモード対応**：OS の設定に合わせて自動で切り替わります

## 使い方

1. `index.html` をブラウザで開きます
2. 「パスワードの長さ」（4〜64文字）と「生成する件数」（1〜20件）をスライダーで決めます
3. 使用する文字の種類を選びます（初期状態は大文字・小文字・数字）
4. 「パスワードを生成する」を押します
5. 各行の「コピー」、または「すべてコピー」でクリップボードにコピーします

> コピー機能はクリップボード API を使うため、`https://` または `localhost` など安全なコンテキストで開くと確実に動作します。

## 使用する文字

| 種類 | 文字 |
| --- | --- |
| 大文字 | `A`〜`Z` |
| 小文字 | `a`〜`z` |
| 数字 | `0`〜`9` |
| 記号 | `` !@#$%^&*()-_=+[]{}\|;:,.<>? `` |

## 強度（エントロピー）の計算

選んだ文字種をすべて含むパスワードの総数を包除原理で数え、その log2 をビット数として表示しています。

| ビット数 | 表示 |
| --- | --- |
| 40 未満 | 弱い |
| 40〜63 | 普通 |
| 64〜95 | 強い |
| 96 以上 | 非常に強い |

## セキュリティ

- Content-Security-Policy で外部への通信を Google Fonts の読み込みのみに制限しています
- 生成結果は `textContent` で描画しており、記号が HTML として解釈されることはありません
- 安全な乱数が使えないブラウザでは、生成ボタンを無効にします
